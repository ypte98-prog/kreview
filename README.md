# kreview — 국민취업지원제도 수급심사 도우미 (기획 단계)

> 심사 자료를 한 장씩 프린트해서 눈으로 대조하던 일을, 조금 덜 힘들게 만들어 보려는 프로젝트예요.

## 어떤 문제를 풀려고 하나요?

국민취업지원제도 수급 심사를 하려면 고용24, 바로원, 행복이음, 4대보험, 등본 자료를 하나하나 열어 보고, 프린트해서, 손으로 맞춰 봐야 해요.
그러다 보니 **한 건에 10~30분**이 걸리고, 하루에 30건 넘게 처리해야 하는 담당자에게는 꽤 큰 부담이에요.

## 무엇을 만들려고 하나요?

자료 파일을 폴더에 넣으면, 지침 기준으로 **1유형 / 2유형 판정 초안**을 만들어 주는 도우미예요.

- 가구원의 재산·소득·취업상태를 자료끼리 대조해요.
- 자료끼리 값이 다르거나 판단이 애매하면 **"특이사항"으로 따로 표시**해 줘요.
- **최종 판정은 언제나 담당 공무원이 해요.** 도우미는 검토를 돕기만 하고, 대신 결정하지 않아요.

## 어떻게 동작하나요? (계획)

```
raw/  ← 민원인별 자료 파일을 넣어요 (예: 접수번호_고용24.pdf)
 ↓
 도우미가 자료를 묶고 → 가구원 확인 → 재산·소득·취업상태 대조 → 판정 초안 작성
 ↓
out/  ← 결과가 나와요
       · [접수번호]_판정초안.md   (민원인별 판정과 근거)
       · 판정결과_전체.xlsx       (한눈에 보는 요약표)
```

## 지금은 어디까지 왔나요?

아직 **기획 단계**예요. 실제로 동작하는 코드는 없어요.

| 순서 | 할 일 | 상태 |
|---|---|---|
| 1순위 | 재산·소득·취업상태 대조 → 유형 판정 초안 | 기획 완료 |
| 2순위 | 직접일자리사업 참여 여부, 실업급여 수급만료 6개월 경과 확인 | 다음에 |
| 3순위 | 서류 보완요청 7일 기한 알림 | 다음에 |

## 개인정보는 이렇게 지켜요

민원인의 재산·소득 같은 정보는 아주 민감해요. 그래서 이렇게 약속해요.

- `raw/`, `out/` 폴더와 PDF·엑셀·이미지 파일은 **GitHub에 절대 올라가지 않도록** 막아 두었어요. ([.gitignore](.gitignore))
- 개발과 테스트는 **가상 데이터로만** 해요. 실제 자료는 기관의 승인을 받은 뒤, 허용된 환경에서만 다뤄요.
- 자료를 외부(이메일, 메신저 등)로 보내지 않고, 원본 파일을 고치거나 지우지 않아요.

더 자세한 내용은 [SECURITY_REVIEW.md](SECURITY_REVIEW.md)를 봐 주세요.
